The request lifecycle

  1. Accept a new client connection.
  2. Read bytes without blocking the event loop.
  3. Parse the request line, headers, and optional body.
  4. Select a server block and matching route.
  5. Build the status line, headers, and response body.
  6. Write every byte, then reuse or close the connection.

Each step has its own edge cases—which is precisely what makes building a web server such a good systems-programming exercise.
